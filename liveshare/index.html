Advanced: relay server

Live Share connects the two phones through a tiny relay you host (it only passes encrypted bytes, stores nothing). Paste your relay address once — it gets baked into every link you create, so people you invite never set anything.

🔒 The key lives inside the link (after the #), which browsers never send to a server. Location, voice and video travel directly between the phones, encrypted. Nothing is stored anywhere.
