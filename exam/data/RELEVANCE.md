# PYQ relevance — how every question is scored

A question may appear in a mock test only if an **independent reviewer** (not
the one who wrote it) scores its relevance to the exam's previous-year papers
(PYQs) at **90 or more out of 100**, and has re-solved it to the same answer.

## 1. The PYQ blueprint (per exam)

`pyqBlueprint.archetypes` lists the question *types* that actually appeared in
the last 3 years' papers — the concept, the format and the usual trap — e.g.

```jsonc
{ "id": "ssc-cgl-R07", "section": "reasoning", "topic": "Coding-Decoding",
  "pattern": "Word → code by shifting each letter +k/−k (k alternates); find code of a new word",
  "years": [2023, 2024, 2025], "frequency": "1–2 per shift", "difficulty": "easy" }
```

Archetypes describe patterns in our own words; they never reproduce a real
question (copyright). Each archetype must be backed by at least two of the
analysed years.

## 2. The score (0–100)

| Part | Points | Full marks when… |
|---|---|---|
| A. Archetype match | 30 | The question is clearly an instance of one blueprint archetype — same concept, same format, same kind of trap. |
| B. Syllabus & weightage | 20 | Topic is in the current official syllabus and carries real weight in recent papers. |
| C. Difficulty & time | 20 | Difficulty and solving time match that exam's recent papers (a CGL question should be solvable in ≈36 s, a CAT one may take 2–3 min). |
| D. Wording & options | 20 | Phrasing, numbers and distractors look like the real paper (plausible wrong options built from common mistakes). |
| E. Correctness & currency | 10 | Exactly one correct option, explanation right, facts valid in 2026. |

Any answer mismatch, second correct option, or out-of-syllabus topic is an
automatic reject regardless of points.

## 3. What gets stored on each question

```jsonc
"source": "ai",                      // "ai" = generated by Claude, "curated" = written in the first research round
"archetype": "ssc-cgl-R07",          // must exist in pyqBlueprint.archetypes
"relevance": { "score": 94, "by": "independent-review", "note": "Exact CGL 2024 coding pattern; distractors from ±1 shift errors" },
"verified": true                     // reviewer re-solved it without seeing the key and got the same answer
```

`node exam/data/validate.mjs` rejects any question with relevance below 90, an
unknown archetype, or `verified` not true. The test engine also skips such
questions, so a student can never be served one.
