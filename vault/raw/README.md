# raw — immutable sources

Drop sources here: clipped articles, circulars, PDFs, broker statements, data
exports, transcripts.

**The agent never modifies anything in this directory.** It reads from here and
writes to `../wiki/`. If a source is wrong, that fact goes in a wiki page — the
source itself stays as it was received.

`assets/` holds images downloaded alongside clipped articles. Point Obsidian's
attachment folder here (Settings → Files and links).

Suggested naming: `YYYY-MM-DD-short-slug.md`, dated by publication rather than
by when you clipped it.
